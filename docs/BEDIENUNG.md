# Bedienung – FusionOS

## Starten

| Weg | So geht's |
|---|---|
| Windows (empfohlen) | Doppelklick auf `run.bat` |
| Konsole | `python main.py` |
| Voraussetzung | Python 3.9+ („Add to PATH“ bei der Installation ankreuzen) |

Nach dem Start: Boot-Balken abwarten → am Sperrbildschirm ein **beliebiges Passwort** eingeben und Enter drücken.

## Tastenkürzel

| Taste | Wirkung |
|---|---|
| `Win` (⊞ / Meta) | Startmenü öffnen/schließen |
| `Strg` + `Alt` + `T` | Terminal starten |
| `Esc` | Startmenü schließen |

## Maus

| Aktion | Wirkung |
|---|---|
| Doppelklick auf Desktop-Icon | App starten |
| Rechtsklick auf Desktop | Kontextmenü (Hintergrund, Theme, Apps …) |
| Doppelklick auf Fenstertitelleiste | Maximieren / wiederherstellen |
| Ziehen am Titelfeld | Fenster verschieben |
| Ziehen an den **oberen Rand** | Maximieren (Snap) |
| Ziehen an den **linken/rechten Rand** | Andocken an halbe Bildschirmhälfte (Snap) |
| Ziehen eines angedockten Fensters | Vom Rand lösen, alte Größe zurück |
| Ziehen an der Ecke `◢` | Fenstergröße ändern |
| Klick auf Taskbar-Icon | App öffnen / minimieren / wiederherstellen |

## Terminal-Befehle (`fsh`)

| Befehl | Wirkung |
|---|---|
| `help` | Alle Befehle anzeigen |
| `dir` | Demo-Ordner anzeigen |
| `date` | Datum & Uhrzeit |
| `whoami` | Aktueller Benutzer |
| `echo TEXT` | Text ausgeben |
| `open APP` | App starten, z.B. `open rechner` |
| `apps` | Alle Apps mit Icon auflisten |
| `neofetch` | Systeminfos mit Logo |
| `theme` | Hell/Dunkel umschalten |
| `wallpaper` | Nächsten Hintergrund setzen |
| `ver` | Versionsinfo |
| `cls` | Bildschirm leeren |
| `shutdown` | FusionOS beenden |

## Power-Optionen

Im Startmenü rechts unten hinter `⏻`:
- **Sperren** → Sperrbildschirm
- **Neustart** → komplette Boot-Sequenz erneut
- **Herunterfahren** → FusionOS beenden
