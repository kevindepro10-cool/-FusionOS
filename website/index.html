Dein eigenes OS.
Windows trifft macOS.

FusionOS ist eine echte Desktop-App für Windows – geschrieben in Python, mit Windows-11-Taskbar, Startmenü, 9 Apps und Boot-Erlebnis. Keine Abhängigkeiten. Kein Setup. Einfach starten.

Alles drin, was ein OS braucht

Neun Apps, ein kompletter Desktop, null Abhängigkeiten.

🪟

Taskbar & Startmenü

Mittige Icons wie in Windows 11, Laufend-Punkte, Startmenü mit Suche und angepinnten Apps – per Win-Taste.

🪟

Echte Fensterverwaltung

Verschieben, an der Ecke skalieren, maximieren (Doppelklick auf die Titelleiste), minimieren in die Taskbar.

🖥️

Fusion Terminal

Eigene Shell mit Befehlen wie neofetch, dir, open rechner und theme.

📁

Explorer & Editor

Ordner mit Schnellzugriff und Navigation, Editor mit echten Öffnen-/Speichern-Dialogen.

🎨

Design & Wallpaper

6 Gradient-Wallpaper, Hell- und Dunkelmodus, Windows-Blau als Akzent – umschaltbar in Sekunden.

⚡

Boot & Sperrbildschirm

Boot-Screen mit Ladebalken, Sperrbildschirm mit Uhr – fühlt sich wie ein echtes System an.

Der Mix. Meistens Windows, ein Hauch Apple.

  • Taskbar unten, mittig, mit Start-Button ⊞
  • Startmenü mit angepinnter App-Kachel
  • Fenster-Buttons ─ ▢ ✕, Akzentfarbe Windows-Blau
  • Task-Manager, Explorer, Terminal-Feel

🍎 Von macOS

  • Gradient-Wallpaper & Glas-Farbwelt
  • Sanfte Animationen & abgerundete Optik
  • Boot-Erlebnis mit eigenem Logo ◈
  • Design-Sprache: clean & reduziert

In 3 Minuten am Start

1

Python installieren

python.org/downloads – bei der Installation „Add Python to PATH“ ankreuzen.

2

FusionOS laden

Auf GitHub Code → Download ZIP klicken und entpacken.

3

run.bat starten

Doppelklick auf run.bat → Boot-Balken → Passwort (beliebig) → Desktop. Fertig!
